用 AI 代理（DeepSeek Harness）辅助开发的静态网页练习仓库，包含两个页面：

| 页面 | 说明 |
| --- | --- |
| `demo.html` | 练习 1.1 的演示页：标题 + 切换消息按钮 + 切换次数统计 |
| `index.html` | 个人项目「球迷小站」：赛程筛选、积分榜自动计算、录入比赛 |

## 球迷小站（index.html）

给看球的球迷用的本地小工具：查赛程、看积分榜、自己录入比分。

### 功能

1. **赛程列表与筛选**：内置 6 支球队、9 场示例比赛，可按球队和状态（已结束 / 未开始）筛选。
2. **积分榜自动计算**：根据已结束比赛的比分，算出场次、胜平负、进球、失球、净胜球、积分，按「积分 → 净胜球 → 进球」排序。
3. **录入比赛**：选择主客队、填写比分和日期，提交后赛程与积分榜立即更新，数据保存在浏览器 `localStorage`，刷新不丢失；可一键恢复初始数据。

### 明确不做的功能

- 不做账号登录、不做云端同步（数据仅存本机浏览器）
- 不接入任何外部实时比分接口
- 不做多语言

### 已知限制

- 只保存 6 支内置球队之间的比赛，不能新增球队
- 数据存在浏览器本地，换设备或清空浏览器数据就没了
- 手机端积分榜需要横向滑动查看

## 本地打开

双击 `index.html` 或 `demo.html` 即可，**不需要安装任何依赖、不需要联网**。

## 技术栈

- 纯 HTML + CSS + JavaScript，无框架、无构建步骤
- 无任何外部资源（不引用 CDN、字体或图片）
- 数据持久化：`localStorage`（键名 `football-matches-v1`）
