# my-first-ai-web

一个用纯 HTML + CSS + JavaScript 编写的静态演示页，用来练习「AI 辅助开发 + Git/GitHub 工作流」。

## 功能

- 页面标题「本地演示页」
- 一个按钮，点击后切换页面上的消息文字，并改变消息区配色；再次点击恢复原状

## 如何打开

- 本地：双击仓库中的 `demo.html`（macOS 可直接用 `open demo.html`）
- 在线：GitHub Pages（尚未启用，启用后把链接补在这里）

## 技术说明

- 技术栈：HTML + CSS + JavaScript，全部内联
- 依赖：无。不联网、不需要安装任何东西
- 数据：不保存，刷新页面即回到初始状态

## 文件结构

```
my-first-ai-web/
├── demo.html   # 演示页面（标题 + 切换消息按钮）
└── README.md   # 本文件
```

## 已知限制

- 纯前端演示，没有后端，不会保存任何数据
- 只有一个交互功能，不做路由、不做多页面
